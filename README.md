## 📌 Sobre o Projeto

O objetivo deste projeto foi recriar a interface web da Netflix, praticando fundamentos sólidos de desenvolvimento front-end ao longo de 7 dias de desafios práticos. O foco foi estruturar código limpo, semântico e com fidelidade visual ao serviço de streaming.

---

## ✨ Funcionalidades e Destaques

- **Cabeçalho Fiel:** Navegação completa com menu principal, busca, notificações e seletor de perfil.
- **Seção Hero (Destaque):** Banner principal com sobreposição em degradê, pôster do título em destaque, sinopse e botões de ação (*Assistir* e *Mais informações*).
- **Trilhas de Conteúdo:** Categorias organizadas (*Minha lista*, *Em Alta* e *Séries excêntricas de humor ácido*).
- **Efeito Hover nos Cards:** Animação suave de zoom nos pôsteres ao passar o cursor do mouse.
- **Carrossel em CSS Puro:** Navegação por setas (anterior / próximo) feita exclusivamente com âncoras e seletores CSS, sem necessidade de JavaScript.
- **Rodapé Institucional Completo:** Ícones das principais redes sociais (Font Awesome), grid de 4 colunas de links, botão de código de serviço e copyright oficial.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica (`<header>`, `<main>`, `<section>`, `<footer>`, tags de mídia e SVGs).
- **CSS3:** Flexbox para alinhamento e distribuição, gradientes, transições e efeitos de transformação (`transform: scale`).
- **Google Fonts:** Tipografia personalizada utilizando a família [Poppins](https://fonts.google.com/specimen/Poppins).
- **Font Awesome 6:** Ícones vetoriais para as redes sociais.
- **Git & GitHub:** Versionamento com commits semânticos e publicação no GitHub Pages.

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone git@github.com:patrickksmdev/netflix-clone.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd netflix-clone
   ```

3. **Abra o arquivo `index.html`:**
   - Dê um duplo clique no arquivo `index.html` no seu gerenciador de arquivos, ou
   - Abra utilizando a extensão **Live Server** no Visual Studio Code.

## 🧠 Aprendizados

Durante os 7 dias de código, foram exercitados conceitos essenciais:
- Estruturação de layouts modernos utilizando **Flexbox**.
- Criação de efeitos visuais imersivos com gradientes lineares sobrepostos a imagens de fundo.
- Criação de interatividades nativas em CSS (como carrosséis e animações de hover).
- Boas práticas de acessibilidade semântica (textos alternativos `alt`, atributos `aria-label`).
- Fluxo de trabalho com Git (ramificações, commits descritivos e publicação contínua).
